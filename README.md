# Becoming a Technical Leader

An interactive resource for team leads transitioning to technical leadership roles, without the need to be the most technical person in the room.

## Overview

This project is a single-page web application that presents a comprehensive guide for team leads who want to develop technical leadership credibility without competing with their senior developers' coding expertise. It emphasizes choosing the right "abstraction layer" and communicating technical concepts effectively.

## Key Topics Covered

1. **The Reality Check** - Understanding that you don't need to out-code your developers
2. **Speaking the Technical Language** - How to demonstrate technical credibility through precise communication
3. **Product Knowledge as Technical Knowledge** - Leveraging deep product understanding for leadership
4. **Perception Management** - Building and maintaining technical credibility
5. **Self-Assessment** - Questions to evaluate your current technical leadership capabilities
6. **Problem-First Mind Mapping** - A practical framework for evaluating technical solutions


## Design Philosophy

The design embodies technical precision and clarity:
- **Typography**: Three-font system (monospace for labels, serif for headings, sans-serif for body)
- **Color Palette**: Deep dark background with strategic orange accents for emphasis
- **Information Architecture**: Progressive disclosure with scroll-triggered animations
- **Responsive**: Adapts to mobile and desktop viewports
